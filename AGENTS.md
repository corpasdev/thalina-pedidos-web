# Instrucciones para el agente

## Commits
Use Conventional Commits for all commits, written in English.

- `feat:` new feature
- `fix:` bug fix
- `refactor:` behavior-preserving changes
- `style:` layout / styles
- `docs:` documentation
- `perf:` performance improvements
- `test:` tests
- `build:` build / dependencies
- `ci:` CI configuration
- `chore:` internal tasks or configuration

Format: `<type>(<optional scope>): <lowercase description>`

Examples:
- `feat: add drafts module`
- `fix: fix product loading from the cloud`
- `chore: configure Supabase MCP`
